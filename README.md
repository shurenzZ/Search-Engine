# 🔥 每日热搜早报

把微博、百度、知乎、抖音、B站、今日头条等平台的热搜榜单汇总成一份「今日早报」，早上打开一个页面就能扫完当天热点，不用再逐个平台翻。

**单文件 HTML，纯前端实现，双击即可在浏览器打开，无需服务器、无需安装、无需登录。**

## ✨ 功能特性

- 📰 **早报报头**：早报标题、当前日期与星期、最后更新时间（多久之前）、数据源在线状态徽章（实时 / 部分示例 / 示例数据）
- 🏷 **按内容分类展示**：内置 10 个分类（AI 前沿、科技数码、互联网与商业、财经宏观、学术科研、国际时事、社会民生、健康生活、文化体育、游戏动漫），按标题与摘要的关键词命中自动归类
- 🗂 **按平台分区展示**：每个平台一张卡片，条目含排名（前三名金银铜高亮）、热搜标题、热度值、摘要原文、平台来源标签
- ⭐ **今日要闻**：置顶一屏速览，按标题去重后取热度最高的 10 条，并标注来源平台
- 🔍 **搜索与筛选**：关键词搜索标题/摘要，支持按平台、按分类筛选，三条件可叠加；兼容中文输入法（选词过程中不会打断）
- 🔄 **一键刷新**：抓取过程显示进度（如「抓取中 3/8」），每个平台抓到数据后立即就地替换，不用等全部完成
- 📋 **复制与导出**：复制单条热搜、复制整份早报、导出 TXT、导出 JSON
- ⚙️ **设置**：API 基地址、代理模式（自动 / 关闭 / 自定义）、每平台条数、缓存时长、数据源开关、摘要字段名、清空缓存、恢复默认
- ⌨️ **快捷键**：`R` 刷新，`/` 聚焦搜索，`Esc` 关闭弹窗或清空搜索
- 📱 **移动端适配**：卡片式布局，从桌面多列自适应到手机单列，工具栏自动压缩

## 🚀 使用方式

任选其一：

- 直接双击打开 `每日热搜早报.html`
- 或在仓库 Settings → Pages 里把 `main` 分支根目录设为站点后，通过 `https://shurenzz.github.io/Search-Engine/每日热搜早报.html` 访问

打开后会自动拉取实时数据；若接口不可用，会**自动降级为内置示例数据**，并在卡片上明确标注「示例数据」，不会用假数据冒充实时数据。

抓取结果会缓存到浏览器 `localStorage`（键名 `hot_daily_brief_v1`），下次打开先秒显缓存，再按「缓存时长」决定是否自动刷新。

## 🛠 技术说明

- 纯 HTML + CSS + JavaScript 单文件，零外部依赖（无图片、无字体、无第三方库）
- **限流处理**：60s 公共实例约「每 2 秒 1 次请求」。所有出网请求统一走串行闸门，保证间隔不小于 `REQ_GAP`（初始 2000ms，被限流自动放慢、恢复正常自动提速）；遇 `429` 按响应头的 `Retry-After` 等待后重试同一通道；整轮结束后对限流/超时类失败平台自动补抓一轮
- **多通道降级**：直连（含重试）→ 公共 CORS 代理 / 自定义代理；上游返回 5xx 时直接降级（换代理也是同一个上游，只会白耗时间）
- **多候选接口**：数据源的 `path` 可写成数组，或用 `altPaths` 追加备用地址，主接口挂掉自动顺延
- **扩展方式**：在脚本的 `SOURCES` 数组加一项即可新增平台；在 `CATEGORIES` 数组加一项即可新增分类（`kw` 为正则关键词）
- 分类规则：标题命中权重 ×3、摘要命中权重 ×1，得分最高者胜出，无命中则回落到该平台的默认分类
