今日要闻 跨平台热度最高的 10 条

    数据源状态与使用说明

    使用说明（打开 / 刷新 / 换数据源 / 新增平台）

    1. 如何打开

    • 双击本文件，用 Chrome / Edge / Firefox 打开即可。无需服务器、无需安装、无需登录。
    • 首次打开会自动拉取实时数据；若网络不可用，会自动降级为内置示例数据并给出提示。

    2. 如何刷新

    • 点右上角「↻ 一键刷新」重新抓取全部平台。抓取过程会显示进度（如「抓取中 3/8」），每个平台抓到数据后立即替换示例内容，无需等全部完成。
    • 若某个平台显示红色「示例数据」，把鼠标移到卡片底部可看到失败原因（限流 / 服务端错误 / 超时），稍后再点刷新即可。
    • 启用的数据源越少、抓取越快。默认开启 8 个平台；可在「设置 → 启用的数据源」里增减（关掉一个约省 2 秒）。
    • 数据会缓存到浏览器 localStorage（键名 hot_daily_brief_v1），下次打开先秒显缓存、再按「缓存时长」判断是否自动刷新。
    • 「设置」里可以调整每平台条数、缓存时长、数据源开关，以及「清空缓存」。

    3. 如何替换 / 增加真实数据源

    • 默认使用免费开源的 60s API（https://60s.viki.moe，MIT 协议，已开启 CORS，可直接被本地页面调用）。
    • 在脚本里的 SOURCES 数组新增一项即可，例如：
      {id:'xxx', name:'平台名', short:'简称', icon:'🆕', color:'#1e88e5', path:'/v2/xxx', kind:'list', defaultOn:true}
    • path 换成别家接口的完整地址（以 http 开头时会直接使用，不再拼接 API 基地址）。
    • 限流说明：60s 公共实例约「每 2 秒只允许 1 次请求」（超限返回 429 + Retry-After）。页面已把所有请求排队串行发送，保证间隔不小于 REQ_GAP（初始 2000 毫秒，被限流时自动放慢、恢复正常后自动提速）；遇 429 会按服务端要求等待后重试，整轮结束后还会对失败平台自动补抓一轮。
    • 备用接口：一个数据源可写多个候选地址，例如 path:['/v2/zhihu','https://你的镜像/zhihu']，或加一项 altPaths:['https://备用地址']；主地址失败会自动顺延到下一个。B站接口（/v2/bili）目前服务端 500（B站反爬致使上游解析失败），页面会自动降级为示例数据；待上游修复后无需改动即可自动恢复。
    • kind 说明：list=返回数组；newsItems=data.news 为对象数组；news=data.news 为字符串数组。
    • 若某接口不提供摘要，可在设置里为它加 summaryField 指定摘要字段名（如 description）。
    • 若目标站点不允许跨域，在「设置 → 代理模式」中选择「自动」：先直连（含限流重试），仍失败才用 1 个公共 CORS 代理兜底；若接口本身返回 5xx（上游挂了），换代理也没用，会直接降级省时间。也可以填自建代理（如 Cloudflare Worker）。

    4. 关于「原文内容」

    • 知乎、百度、IT之家、AI 新闻等数据源本身提供正文摘要，页面会直接内联展示。
    • 点条目里的「展开全文」，会就地抓取该条的原文页面并抽出正文，直接显示在条目内，不需要跳出去；抓取结果按链接记忆，重复展开不再请求。
    • 抓取先直连（部分源站开了 CORS），跨域失败再依次换「代理模式」里的公共 CORS 代理；全部失败会在条目里写明原因。
    • 微博、抖音、头条等榜单接口只提供标题与热度值，它们的原文/搜索页多为脚本渲染或需登录，能否抓到正文取决于源站；抓不到时仍可点「原文 ↗」跳转查看，跳转始终保留。
    • 单条正文最多展示 4000 字，超出会截断并提示；点「复制此条」可单独复制该条的标题、摘要与链接。

    5. 快捷键

    • R 刷新　/ 聚焦搜索　Esc 关闭弹窗或清空搜索
